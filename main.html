About BloodSync

BloodSync connects blood donors, patients, and healthcare institutions across Cavite: District 1 through five main features:

Automated Donor Screening

Collects donor records and automatically verifies eligibility based on Philippine DOH standards (age, weight, and 8-week donation interval).

CHECK ELIGIBILITY →

District 1 Hospital Directory

Lists accredited local hospitals with contact info, operating hours, and municipality-based location filtering across Cavite.

FIND HOSPITALS →

Verified Blood Request Board

Allows users to submit emergency blood requests with a doctor's slip requirement to prevent fraud, broadcasting verified needs to the community.

POST REQUEST →

Donation Drive Booking

Displays scheduled mobile blood drives and registration links that enables donors to pre-book time slots to reduce waiting times.

VIEW EVENTS →

Role-Based Portals

Dedicated user dashboards for Donors, Patients, Hospital Personnel, and Admins to manage profiles, requests, and system security.

SIGN IN →
